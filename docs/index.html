WHY NOT A WALLPAPER ENGINE?

Wallpaper engines are built to run anything, so most of them run a whole web browser behind your icons. Ronin is built for one wallpaper and draws it straight on the GPU in one small process. It also does things they don't do at all.

WHAT IT DOES

❄︎LIVING WEATHER

Snow, rain, drifting mist, embers and lightning. Or turn on your real local weather (no API key) and it matches the sky outside.

〰︎MUSIC INK LINE

A gold line along the bottom that dances to whatever is playing in any app, with auto-gain so it moves at any volume. Shows the track and album art too.

◇︎DESKTOP TASK BOARDS

Boards per project, folding sections, three-state tasks, notes and sub-tasks, clickable right on the wallpaper. Icons and windows still get their clicks.

⌨︎TASK HUD

Press Ctrl+Alt+T for a sticky note of your tasks over any app. Tick, add, switch boards, then Esc.

✥︎ARRANGE MODE

Drag the clock, quote, tasks and widgets anywhere, live. Snapping, alignment guides, corner resizing, undo, and drop onto another monitor.

⧉︎BUILT FOR MULTI-MONITOR

Every setting per screen, monitor roles (Main / Side / Ambient), and a panorama that spans them all using their real positions.

▣︎WIDGETS

Calendar from any .ics link (Google, Outlook, iCloud), CPU / GPU / RAM sparklines, a focus timer you click on the desktop, world clocks, album art.

▶︎YOUR BACKGROUNDS

Images, animated GIFs and looping videos. Drop them in a folder and pick them in Settings. Each monitor can have its own.

◷︎SCHEDULED LAYOUTS

Save arrangements as layouts and switch by time of day: a work layout on weekday mornings, a calm one at night.

THE LITTLE EXTRAS

AUTO-UPDATES

Checks this GitHub page once a day. One click in the tray installs the new version and keeps your settings and images.

WORKS IN OTHER ENGINES TOO

The wallpaper is also a standard web wallpaper for Wallpaper Engine and Lively, if you'd rather use those.

MATCHING THEMES

Ronin colour schemes for Windows Terminal, Spotify (Spicetify), the Windhawk taskbar and Start menu, and your accent colour.

SURVIVES EVERYTHING

Explorer restarts, driver updates, monitors plugged in and out. It reattaches behind your icons by itself.

TIME-OF-DAY LIGHT

Dawn, day, dusk and night tint the scene and its glow. Film grain and a slow breathing zoom keep it alive.

FULLY HACKABLE

C# with Direct2D, plus the original HTML page as a second renderer. Fork it, rebrand it, sell it. No credit needed.

LAOZI

INSTALL IN A MINUTE

Download Ronin-x.y.z.zip from Releases.

Unzip it somewhere permanent. For example Documents\Ronin.

Run Start Ronin.cmd. If Windows warns you, click More info → Run anyway (the app isn't code-signed).

Click the gold ◆ in the tray for settings. Right-click → Start with Windows.

Needs Windows 10 (2004+) or 11, 64-bit. The settings window uses the Edge WebView2 Runtime, which Windows 11 already has.
